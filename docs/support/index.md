# Support

## Prepare your request

Include the following so your product and issue can be identified:

- Product model and physical variant; a clear photo of the device label is useful.
- Hub or coordinator, integration name and software version, where applicable.
- A short description of the issue and when it started.
- Steps already tried and the exact error message, if any.
- Relevant screenshots, with personal information hidden.

## Contact options

Verified Besisglas support contact details have not yet been published here. If you purchased through a marketplace, use the seller-contact option in your order details.

Do not post order numbers, addresses or other personal details in public comments.
